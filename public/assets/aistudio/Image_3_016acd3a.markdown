## Brand & Style
The brand personality reflects rigorous precision, structural clarity, and academic momentum. Built for engineering and dual-degree undergraduates orchestrating complex prerequisite chains and multi-program curricula, the interface merges high-density computational graphs with tactile legibility. The design rejects sterile, dated enterprise campus portals in favor of a modern, data-dense academic engineering workspace.

The visual style is **Modern Technical Precision**:
- Crisp, structural card surfaces with refined hairline borders.
- Monospaced code-like identifiers paired with modern geometric grotesque sans-serifs for maximum clarity under dense layouts.
- Vibrant, semantically disciplined node accents against deep slate foundations that distinguish prerequisite branches, equivalencies, and academic statuses at a glance.
- Restrained glass and tonal surfaces that maintain visual balance across dense panoramic canvas graphs and structured audit matrices.

## Colors
The palette leverages a deep structural slate base paired with vibrant academic navigation accents and unambiguous status vectors:

- **Primary Canvas & Chrome (`#0F172A` / `#1E293B`)**: Serves as the authoritative backbone for key navigation, high-contrast headings, active timeline stages, and dominant interface landmarks.
- **Electric Blue Accent (`#2563EB`)**: Denotes primary interaction vectors, active curriculum pathways, active graph edge flows, and selection states.
- **Teal / Cyan Accent (`#0D9488`)**: Distinguishes multimedia engineering tracks, elective specializations, and completed track milestones.
- **Dual-Degree Purple (`#8B5CF6`)**: Applied strictly to corequisites, cross-listed degree equivalencies, and dual-program validation states.
- **Status Anchors**:
  - **Passed / Aprobada (`#10B981`)**: Emerald green signaling completed credits and fulfilled prerequisites.
  - **In Progress / Warning (`#F59E0B`)**: Amber gold alerting students to locked prerequisites, pending milestones, or sequence warnings.
  - **Failed / Reprobada (`#EF4444`)**: Rose crimson marking failed subjects requiring immediate retake scheduling.
- **Neutrals & Surfaces**: Backgrounds default to clean technical light tones (`#F8FAFC` base canvas, `#FFFFFF` cards, `#E2E8F0` structural borders), backed by `#64748B` slate text for secondary metadata. In dark canvas modes, surfaces step from `#0F172A` (backdrop) to `#1E293B` (nodes and panels) with `#334155` subtle boundaries.

## Typography
Typography is tuned for technical rigor, maximum scan efficiency, and hierarchical contrast:

- **Headlines & Section Titles (Plus Jakarta Sans)**: Provides modern authority with subtle geometric warmth, anchoring semester headers, dual-degree summaries, and modal views.
- **Body & Dense Grid Data (Inter)**: Delivers unmatched legibility for complex tabular views, curriculum requirement sheets, and prerequisite descriptions.
- **Code & Course Identifiers (`code-badge`)**: Used for course codes (e.g., `MAT-204`, `MMED-310`, `CS-101`) with uppercase styling and tabular numeric figures for horizontal scan alignment.
- **Micro-Scale Legibility**: Line heights are kept compact (`1.3x` to `1.45x`) on node representations to conserve canvas space while maintaining strict legibility in multi-level dependency lists.

## Layout & Spacing
The layout employs an analytical dual-mode structure: an infinite or zoomable fluid graph workspace paired with a rigid 12-column academic schedule grid.

- **Desktop (>= 1280px)**: 12-column layout with `gutter-lg` (1.75rem / 28px) and `margin-desktop` (2.5rem / 40px). Academic terms are organized horizontally as sequential columns, allowing left-to-right temporal progression with interactive Bézier curves connecting prerequisite nodes.
- **Tablet (768px - 1279px)**: 8-column layout with `gutter` (1.25rem / 20px). The curriculum graph transitions to a horizontally swipeable semester rail with sticky academic header metadata.
- **Mobile (< 768px)**: 4-column layout with `margin-mobile` (1rem / 16px) and `gutter-sm` (0.75rem / 12px). Graph nodes stack into expandable vertical terms, with prerequisite dependencies revealed through tap-to-focus breadcrumbs and bottom-sheet inspectors.
- **Component Padding Scale**: Internal card paddings follow a disciplined density rhythm: `space-xs` (4px) for pill tags, `space-sm` (8px) for compact course badges, `space-md` (12px) for graph node content, and `space-lg` (20px) for analytics drawer modules.

## Elevation & Depth
Depth is maintained through clean surface layering and razor-sharp borders rather than heavy, muddy shadows:

- **Ground Level (Canvas)**: `#F8FAFC` base surface for the main workspace and infinite graph canvas, patterned with an optional subtle SVG coordinate grid (dots spaced at 24px in `#CBD5E1`).
- **Surface Level 1 (Course Nodes & Semester Columns)**: `#FFFFFF` background with a crisp 1px border (`#E2E8F0`). Shadow is ultra-diffused: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.04)`.
- **Surface Level 2 (Active / Hovered Graph Nodes & Tooltips)**: Elevated via `0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.04)` combined with an active border tint matched to the subject's path color (e.g., `#2563EB` or `#8B5CF6`).
- **Overlay Level 3 (Inspector Drawers & Dependency Modals)**: Floats above canvas with `0 20px 25px -5px rgba(15, 23, 42, 0.12), 0 8px 10px -6px rgba(15, 23, 42, 0.06)`, framed by a 1px `#CBD5E1` border and a frosted glass backdrop filter (`backdrop-blur-md` over `#0F172A/20`).
- **Graph Connection Layers**: Dependency lines sit directly above the grid canvas but beneath node cards (`z-index: 10`). Selected path connectors gain a vibrant glow via `drop-shadow(0 0 4px currentColor)` at 60% opacity.

## Shapes
The design system adopts a **Soft (Level 1)** geometry (`0.25rem` / 4px base radius, `0.5rem` / 8px for cards, and `0.75rem` / 12px for modal panels) accented by full circular capsules (`9999px`) for contextual pill tags:

- **Course Node Cards**: Structured rectangular forms with `rounded-md` (6px to 8px) corners to preserve maximum internal content area and maintain visual alignment in column stacks.
- **Pill Tags & Status Chips**: Fully rounded pill shapes (`rounded-full`) provide organic contrast against the geometric course nodes, creating instantaneous optical separation between course metadata and container edges.
- **Connector Nodes**: Small circular docking points (8px diameter) along node edges to cleanly anchor prerequisite SVG paths.

## Components

### 1. Course Node Cards
- **Structure**: Compact rectangular container (`width: 100%`, max 260px in graph view).
- **Header**: Left-aligned course code (`code-badge` in `#64748B`), right-aligned academic credit count pill (e.g., `3 CR`).
- **Body**: Course name in `headline-sm` (Inter 14px SemiBold, `#0F172A`), truncated at 2 lines.
- **Footer**: Status chip paired with dependency indicators (e.g., `Pre: 2`, `Co: 1`).
- **Borders & Left Stripe**: 1px subtle neutral border around the card, reinforced by a 3px vertical accent stripe on the left edge denoting track affiliation (Teal for Multimedia, Purple for Dual Degree, Blue for Core Engineering).

### 2. Status Chips & Pill Tags
- **Approved / Aprobada**: Light emerald fill (`#ECFDF5`), deep emerald text (`#065F46`), left-side dot indicator (`#10B981`).
- **Pending / Warning**: Amber tint (`#FFFBEB`), warm amber text (`#92400E`), alert dot (`#F59E0B`).
- **Failed / Reprobada**: Soft rose fill (`#FEF2F2`), sharp red text (`#991B1B`), cross dot (`#EF4444`).
- **Dual-Degree / Corequisite**: Lavender fill (`#F5F3FF`), deep violet text (`#5B21B6`), diamond glyph (`#8B5CF6`).

### 3. Buttons
- **Primary**: Solid `#0F172A` background, white label, `rounded-md` (6px), 8px 16px padding. Active state transitions to `#1E293B` with 1px inset electric blue ring on focus.
- **Secondary / Action**: Crisp `#FFFFFF` surface with `#CBD5E1` border, `#0F172A` label; hover brings `#F8FAFC` surface and `#2563EB` text.
- **Path Highlight Button**: Ghost button with `#2563EB` typography and a transparent fill that shifts to `#EFF6FF` on hover to trace dependencies across the curriculum graph.

### 4. Graph Path Connectors (SVG Edges)
- **Neutral (Default)**: `#CBD5E1` stroke, 1.5px width, smooth Bézier curvature.
- **Active / Focused Dependency**: `#2563EB` stroke, 2.5px width, directional animated pulse or arrowhead.
- **Prerequisite Warning**: `#F59E0B` stroke, 2px dashed pattern (`stroke-dasharray: 4 3`).
- **Cross-Program / Equivalency**: `#8B5CF6` stroke, 2px dotted pattern with endpoint badge.

### 5. Curriculum Metrics Bar
- Top-level sticky banner tracking: Cumulative GPA, Total Earned Credits / Required Credits (e.g., `138 / 164 CR`), Program Completion Percentage gauge, and Dual-Degree Equivalency Progress. Uses tabular numbers, subtle progress rails with `#2563EB` fills, and quick-filter toggle chips for terms 1 through 10.
